---
description: Turn the open unknowns in this project into a Decision Questionnaire for the user
---

Collect everything currently blocked on a decision only the user can make — a brand colour,
missing content, a layout the backlog does not settle, a token whose value disagrees between
mockup files, a plugin that would need installing — and present it as a **clickable question
panel**, not prose.

Rules:

- Batch related decisions into one panel rather than interrupting repeatedly.
- Ground every option in something you measured, and say the number.
- State the trade-off of each option honestly, including the one you did not recommend.
- Never invent content to fill a gap. A missing testimonial is a question, not a writing task.
- Do not ask about things you can settle yourself from the code, the backlog, or a sensible
  default. Decide those and say what you decided.

Afterwards, record the answers in the project's decision log so the reasoning survives.
